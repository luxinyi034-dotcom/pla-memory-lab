# PLA Memory Lab

为 VCE EAL **Analysing argument（PLA）** 写作积累表达和词汇的个人学习网站。以 iPad 横屏为主，也支持电脑和手机，可以离线使用，数据保存在本机。

## 功能

| 页面 | 内容 |
|---|---|
| 今日学习 | 显示今日进度、预计用时和打卡状态；进入新学和到期复习；今日词表（今日新学、今日复习，按分组折叠）和今日错词 |
| 新学 | 表达积累和词汇积累按日期交替；目标 20、40、60、100 条或自定义；按最早导入顺序推荐完整分组；可恢复推荐、全选、一键取消、预览 |
| 学习 / 复习 | 每组先认读：看英文，选认识或不认识，再看完整卡片。然后整组默写，写错的放到本组最后重写，直到写对。退出时保存位置和已输入的内容 |
| 表达库 | 全部 / 表达积累 / 词汇积累三个标签；搜索；三种排序；两列分组卡片；双击改名；长按拖动排序；批量改类别或删除；导入 Excel / CSV |
| 掌握与计划 | 按分组看六个复习节点（1、2、4、7、15、30 天），点今日或逾期的节点可直接复习；按单词按掌握度筛选，点分组标签跳到该组 |
| 快速刷词与错词本 | 左滑表示熟悉，右滑表示不熟悉并加入错词本，以最后一次为准。错词默写一轮一轮进行，写对一条移除一条 |
| 打卡日历 | 显示连续和累计打卡天数；补打卡每月最多 2 次 |
| 设置 | 导出备份（带内容校验），合并或完全替换导入，每日自动快照，发音设置（美式、英式、澳式） |

学习日按北京时间计算，每天凌晨 **2:00** 切换。

## 部署（GitHub Pages）

这是纯静态网站，不需要构建：

1. 仓库 **Settings → Pages**，Source 选 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`。
2. 等一两分钟后打开 `https://<用户名>.github.io/pla-memory-lab/`。
3. 在 iPad Safari 里点 **分享 → 添加到主屏幕**，以后从主屏幕打开，全屏且可离线使用。

本地预览：`npm run serve`，然后打开 http://localhost:8080 。

## 数据

- 第一次打开时，网站会载入 `data/seed.json`，这是 2026-10-15 导出的学习数据：135 组、546 条表达、232 条进度、11 天打卡。之后所有改动都只保存在这台设备的浏览器里，`seed.json` 不会再被读取，也不会覆盖已有数据。
- 换设备或清理浏览器之前，请到 **设置 → 导出完整备份**，然后在新设备上导入。
- 导入只恢复数据，不会改变网站的功能和界面。导入是原子操作，出错时什么都不会改。

## 开发

```
src/core/   纯逻辑：学习日（time）、复习节点（srs）、数据导入导出（model）、
            派生数据（selectors）、修改操作（actions）、学习流程（study）、
            快速刷词与错词默写（drills）、默写判分（grading）、表格读取（xlsx）
src/views/  各页面
src/store.js  状态、本地保存、每日快照
```

运行测试：`npm test`（Node 22+）。
